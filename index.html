02 / Animação · GSAP

01 / 03

GSAP é uma biblioteca de animação para a web. Com ela, o scroll vira o controle do tempo. Role e veja.

  1. 01 Sequência

    Vários elementos entram em ordem, como numa coreografia.

    gsap.from('.forma', { y: 120, stagger: 0.08 })

  2. 02 Scroll no controle

    A animação avança e volta junto com o seu scroll.

    scrollTrigger: { scrub: true }

  3. 03 Caminhos

    Um objeto percorre uma rota desenhada, como um satélite em órbita.

    motionPath: { path: '#orbita' }
